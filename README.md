# SQL-PRACTICE


## 📌 Objective
This project demonstrates core SQL fundamentals by practicing CRUD operations
(Create, Read, Update, Delete) using two different database systems:
- SQLite
- Oracle Database

The goal is to understand how SQL works independently of Java and how syntax
and data types differ across databases.

---

## 🛠 Tools Used
- SQLite (via https://www.sqlitetutorial.net/)
- Oracle Database (SQL*Plus / SQL Developer)
- Git & GitHub for version control
